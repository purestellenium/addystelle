*Beyond the "familiar path" of your usual YouTube Shorts Reddit Stories, lies the "hidden orbit": coins that unlock faster speed and a cool aura around your player.*

# Gameplay:
A -> Left <br>
D -> Right <br>
W/Space -> Jump <br>
S -> Down <br>
K -> Dash

Dashes can be in any direction, other than straight up, but must be done in the air.

you can pick up Coins behind the ticker to speed up, and have a stronger dash, the amount of coins can be visualized with the size of the character's aura

the Ticker text is scraped from reddit(AmITheAsshole)


# Folder structure for Development

- `src` - source code for your kaplay project
- `dist` - distribution folder, contains your index.html, built js bundle and static assets


## Development

```sh
$ npm run dev
```

will start a dev server at http://localhost:8000

## Distribution

```sh
$ npm run build
```

will build your js files into `dist/`

```sh
$ npm run zip
```

will build your game and package into a .zip file, you can upload to your server or itch.io / newground etc.
